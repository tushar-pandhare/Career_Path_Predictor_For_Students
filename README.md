# Career Path Predictor for Students

Career Path Predictor is a Machine Learning-based career recommendation platform that helps students identify suitable career domains based on their academic performance, aptitude scores, technical skills, interests, and extracurricular activities.

The project is designed to demonstrate concepts related to:

- Machine Learning Classification
- Data Preprocessing & Feature Engineering
- Ensemble Learning Techniques
- Educational Data Mining
- Model Evaluation & Optimization
- Interactive Dashboard Development
- Data-Driven Career Guidance

## Features

- Career prediction based on student academic and skill profiles
- Support for multiple career domains and recommendations
- Advanced data preprocessing and missing value handling
- Feature engineering from academic, aptitude, and extracurricular data
- Ensemble learning using Random Forest and SVM
- Interactive Streamlit dashboard for predictions
- Real-time recommendation generation
- Model performance visualization and analytics
- User-friendly interface for student assessment

## Getting Started

Clone the repository:

```bash

cd career-path-predictor
```

Install dependencies:

```bash

```

Open:

```text

```

## Project Workflow

1. Student enters academic, aptitude, and skill-related information.
2. Input data is cleaned and preprocessed.
3. Feature engineering extracts meaningful indicators.
4. Trained ML models evaluate the profile.
5. Ensemble voting generates the final prediction.
6. Recommended career paths are displayed through the dashboard.
